# FILTER-HOAX
Web ini merupakan integrasi inovatif yang berasal dari permasalahan yang terjadi di zaman digitalisasi saat ini, yaitu minim literasi yang menyebabkan hoax dan permasalahan lebih besar seperti cyberbullying. Web ini di lengkapi fitur cek hinformasi apakah sesuai fakta atau tidak hanya dengan menempel informasi pada alat yang disediakan.
